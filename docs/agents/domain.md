# Domain docs

## Read before changes

- Read `CONTEXT.md` at the repository root.
- Read relevant decisions under `docs/adr/`.
- If a file is absent, continue without it.

## Layout

This repository uses one domain context:

- `CONTEXT.md` contains the glossary.
- `docs/adr/` contains architecture decisions.

## Vocabulary

Use the terms defined in `CONTEXT.md` in issues, tests, code, and documentation.

Record a terminology gap for the `domain-modeling` skill.

## Decisions

Report a conflict with an architecture decision before you propose a conflicting change.
