# Triage labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue |
| `needs-info` | `needs-info` | The reporter must provide information |
| `ready-for-agent` | `ready-for-agent` | An agent can implement the issue |
| `ready-for-human` | `ready-for-human` | A human must implement the issue |
| `wontfix` | `wontfix` | The issue will not be implemented |

Use the GitHub label for each matching skill role.
